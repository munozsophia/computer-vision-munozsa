A1. Softmax and cross-entropy   [14 points]¶

A classifier produces logits $\mathbf{z} \in \mathbb{R}^K$. The softmax turns them into probabilities, and the cross-entropy compares these with a one-hot target $\mathbf{y}$:

$$\hat{y}_j = \frac{e^{z_j}}{\sum_{l=1}^{K} e^{z_l}}, \qquad J = -\sum_{j=1}^{K} y_j \log \hat{y}_j .$$

(a) [6] Show that $$\frac{\partial \hat{y}_j}{\partial z_k} = \hat{y}_j\,(\delta_{jk} - \hat{y}_k),$$ where $\delta_{jk}$ is 1 if $j = k$ and 0 otherwise. Treat the cases $j = k$ and $j \neq k$ separately.

(b) [6] Use (a) and the chain rule to show that $$\frac{\partial J}{\partial \mathbf{z}} = \hat{\mathbf{y}} - \mathbf{y}.$$ State clearly where you use the fact that $\mathbf{y}$ is one-hot. Does the result still hold if $\mathbf{y}$ is any probability vector, not necessarily one-hot?

(c) [2] In practice the loss is averaged over a batch of $B$ examples, $J_{\text{batch}} = \frac{1}{B}\sum_{b=1}^{B} J^{(b)}$. What is $\partial J_{\text{batch}} / \partial \mathbf{z}^{(b)}$ for one example $b$ in the batch?

You will implement exactly this gradient in B3.

Your answer — A1¶

(a) To prove the case $j=k$, I used the Quotient Rule, $f(x) = \frac{u(x)}{v(x)} \rightarrow f'(x) = \frac{u'(x)v(x)-u(x)v'(x)}{v(x)^2}$, from basic calculus. To break down $\frac{\partial \hat{y}_j}{\partial z_k} = \hat{y}_j\,(\delta_{jk} - \hat{y}_k)$, I first assigned $S = \sum_{l} e^{z_l}$. In this case I substituted $S$ into $\hat{y}_j = \frac{e^{z_j}}{S}$ and $\frac{\partial S}{\partial z_k} = e^{z_k}$.

Case $j = k$: To compute $\frac{\partial \hat{y}_j}{\partial z_j}$, I used the Quotient Rule, $u=e^{z_j} \rightarrow u'=e^{z_j}$ and $v=S \rightarrow v' = \frac{\partial S}{\partial z_j}=e^{z_j}$. Substituting into the expression, I ended up with $\frac{e^{z_j} \cdot S - e^{z_j} \cdot e^{z_j}}{S^2} = \frac{e^{z_j} \cdot S}{S^2} - \frac{e^{z_j} \cdot e^{z_j}}{S^2} = \frac{e^{z_j}}{S} \cdot \frac{S}{S} - \frac{e^{z_j}}{S} \cdot \frac{e^{z_j}}{S}$. Since $\hat{y}_j = \frac{e^{z_j}}{S}$, I can substitute $\hat{y}_j$ into the current simplified expression, $\hat{y}_j \cdot \frac{S}{S} - \hat{y}_j \cdot \hat{y}_j = \hat{y}_j \cdot 1 - \hat{y}_j \cdot \hat{y}_j = \hat{y}_j (1 - \hat{y}_j)$. This means that $\delta_{jk}=1$ and $\hat{y}_k=\hat{y}_j$ which proves that if $j=k$ then $\hat{y}_j(1-\hat{y}_j)$.

Case $j \neq k$: Using $\hat{y}_j = \frac{e^{z_j}}{S}$ to differentiate $\hat{y}_j$, I set $\hat{y}_j = e^{z_j} \cdot S^{-1}$ and applied the Chain Rule, $f(x)=g(h(x)) \rightarrow f'(x)=g'(h(x)) \cdot h'(x)$. With the applied rule, $g(h)=S^{-1} \rightarrow g'(h)=-S^{-2}$ and $h(x)=S \rightarrow h'(x)=\frac{\partial S}{\partial z_k}$. Inserting the values into the Chain Rule gives me the expression $f'(x)=g'(S) \cdot \frac{\partial S}{\partial z_k}=-S^{-2} \cdot \frac{\partial S}{\partial z_k}$. To simplify the expression, $\frac{\partial \hat{y}_j}{\partial z_k}=e^{z_j} \cdot \frac{\partial}{\partial z_k} S^{-1}=-S^{-2} \cdot e^{z_k} \cdot e^{z_j}=-\frac{e^{z_k}e^{z_j}}{S^2}=-\frac{e^{z_k}}{S} \cdot \frac{e^{z_j}}{S}=-\hat{y}_k \hat{y}_j$. This means that $\delta_{jk}=0$ and $j \neq k$ then $-\hat{y}_k \hat{y}_j$.

(b) Using the loss $J = -\sum_{j=1}^{K} y_j \log \hat{y}_j$, differentated $\hat{y}_j=\frac{e^{z_j}}{\sum_{l}e^{z_l}}$, and the Chain Rule.

I differentiated $J$, since $\frac{d}{dx}log x = \frac{1}{x} \rightarrow \frac{\partial J}{\partial \hat{y}_j}=-\frac{y_j}{\hat{y}_j}$ with respect to $\hat{y}_j$.

Since $z_k$ changes every $\hat{y}_j$, then $\hat{y}_j$ changes $J$, each change must be summed, $\frac{\partial J}{\partial z_k}=\sum_{j}\frac{\partial J}{\partial \hat{y}_j} \cdot \frac{\partial \hat{y}_j}{\partial z_k}$. Substituting with the provided expressions, $\frac{\partial J}{\partial z_k}=\sum_{j} (-\frac{y_j}{\hat{y}_j})\hat{y}_j (\delta_{jk}-\hat{y}_k)=-\sum_{j} y_j(\delta_{jk}-\hat{y}_k)=-\sum_{j} y_j\delta_{jk}+\hat{y}_k\sum_{j} y_j$.

$-\sum_{j} y_j\delta_{jk}=-y_k$ since $\delta_{jk}=0$ when $j \neq k$, and $j=k$ term is the only one left.

$\hat{y}_k \sum_{j} y_j = \hat{y}_k \cdot 1=\hat{y}_k \leftarrow$ y one-hot is applied here $\sum_{j} y_j = 1$.

With both sums added, $\frac{\partial J}{\partial z_k}=\hat{y}_k - y_k$ and it corresponds with $\frac{\partial J}{\partial \mathbf{z}} = \hat{\mathbf{y}} - \mathbf{y}$. I do think the $\mathbf{y}$ would still hold if it is any probability vector because the entries would still add up to $1$.

(c) Using $J_{\text{batch}} = \frac{1}{B}\sum_{b=1}^{B} J^{(b)}$ to find $\partial J_{\text{batch}} / \partial \mathbf{z}^{(b)}$ and assigning $B=2$ the batch loss would look like $J_{\text{batch}}=\frac{1}{2} J^{(1)}+\frac{1}{2} J^{(2)}$.

The loss for the first image is $J^{(1)}$ using the image's logits $z^{(1)}$. The same can be said for the second image. Taking the derivative with respect to $z^{(1)}$, $\frac{1}{2} J^{(1)} \rightarrow \frac{1}{2} \frac{\partial J^{(1)}}{\partial z^{(1)}}$ and $\frac{1}{2} J^{(2)} \rightarrow 0$. This happens because for any $b$, the term $J^{(b')}$ where $b' \neq b$ is only dependent on $z^{(b')}$ and derives to $0$ with respect to $z^{(b)}$.

Meaning that $\frac{\partial J_{\text{batch}}}{\partial \mathbf{z}^{(b)}}=\frac{1}{B} \cdot \frac{\partial J^{(b)}}{\partial z^{(b)}}$. Applying (b)'s expression, $\frac{\partial J}{\partial z_k}=\hat{y}_k - y_k$, $\frac{\partial J_{\text{batch}}}{\partial \mathbf{z}^{(b)}}=\frac{1}{B}(\hat{y}^{(b)} - y^{(b)})$. Taking a deeper look at the expression, $\frac{1}{B}$ basically shows that as the batch size grows, the example's gradient shrinks meaning the total gradient stays the same size.

A2. Shared parameters   [8 points]¶

(a) [4] A scalar parameter $\theta$ is used in two places in a computation graph, so that $J = f\big(g(\theta),\, h(\theta)\big)$. Show that $$\frac{dJ}{d\theta} = \frac{\partial f}{\partial g}\frac{dg}{d\theta} + \frac{\partial f}{\partial h}\frac{dh}{d\theta}.$$ Explain how this relates to the branch module of Chapter 14, §14.7.

(b) [4] A one-dimensional convolutional layer computes $x_{\text{out}}[n] = \sum_{k} w[k]\, x_{\text{in}}[n+k]$. The same weight $w[k]$ is used at every position $n$. Using (a), write $\partial J / \partial w[k]$ in terms of the incoming gradient $g[n] = \partial J / \partial x_{\text{out}}[n]$ and the input. Then explain in two or three sentences why this rule is what makes convolutional layers trainable, and why it lets them learn from less data than a fully connected layer.

You will implement the two-dimensional version of this in the next assignment.

Your answer — A2¶

(a) When there is a change in $\Delta\theta$, $\Delta g$ changes by the derivative $\frac{dg}{d\theta}\Delta\theta$ and $\Delta h$ changes by the derivative $\frac{dh}{d\theta}\Delta\theta$. For $\Delta f$, since it is dependent it will be manipulated by both changes. So the total sum in this case would be $\Delta f=\frac{\partial f}{\partial g}\Delta g + \frac{\partial f}{\partial h}\Delta h=\frac{\partial f}{\partial g}\frac{dg}{d\theta}\Delta\theta + \frac{\partial f}{\partial h}\frac{dh}{d\theta}\Delta\theta$.

$$\frac{dJ}{d\theta}=\lim_{\Delta\theta \to 0}\frac{\Delta f}{\Delta\theta}=\frac{\partial f}{\partial g}\frac{dg}{d\theta}+\frac{\partial f}{\partial h}\frac{dh}{d\theta}$$

This proof relates to the branch as $\theta$ has shared parameters in $g$ and $h$. This means it's a $\text{branch}(x)=[x,x] \rightarrow \text{branch}(\theta)=[\theta,\theta]$ and going backwards, according to Section 14.7, $g_{in}=g^{a}_{out}+g^{b}_{out}$ the gradients from every downstream path are simply added. Again, from the slides in summary $\frac{\partial J}{\partial \theta}=\sum_i{\frac{\partial J}{\partial \theta^i}}$. Breaking it down $\frac{\partial f}{\partial g}\frac{dg}{d\theta}$ is the gradient arriving through $\theta$ that feeds $g$ and $\frac{\partial f}{\partial h}\frac{dh}{d\theta}$ is the gradient arriving through $\theta$ that feeds $h$.

(b) The convolution layer is $x_{\text{out}}[n] = \sum_{k} w[k]\, x_{\text{in}}[n+k]$, based of Section 24.2. For example, to have a better understanding of the numerical values, inserting a kernel with weights, $k=0,1$, and $3$ outputs, $n=0,1,2$. That would mean $4$ inputs from $x_{\text{in}}[0]$ through $x_{\text{in}}[3]$.

$x_{\text{out}}[0]=w[0]x_{\text{in}}[0]+w[1]x_{\text{in}}[1]$

$x_{\text{out}}[1]=w[0]x_{\text{in}}[1]+w[1]x_{\text{in}}[2]$

$x_{\text{out}}[2]=w[0]x_{\text{in}}[2]+w[1]x_{\text{in}}[3]$

Observing the results above, every weight shows up in every output, so by (a), its gradient is the sum over all the outputs.

For $w[0]$:

$$\frac{\partial J}{\partial w[0]} = \sum_{n}\frac{\partial J}{\partial x_{\text{out}}[n]}\frac{\partial x_{\text{out}}[n]}{\partial w[0]} = g[0]\,x_{\text{in}}[0] + g[1]\,x_{\text{in}}[1] + g[2]\,x_{\text{in}}[2]$$

For $w[1]$:

$$\frac{\partial J}{\partial w[1]} = \sum_{n}\frac{\partial J}{\partial x_{\text{out}}[n]}\frac{\partial x_{\text{out}}[n]}{\partial w[1]} = g[0]\,x_{\text{in}}[1] + g[1]\,x_{\text{in}}[2] + g[2]\,x_{\text{in}}[3]$$

The pattern that shows up from the above computations is that for $w[0]$, the input next to $g[n]$ is $x_{\text{in}}[n]$, and for $w[1]$, the input next to $g[n]$ is $x_{\text{in}}[n+1]$. So for general $k$:

$$\frac{\partial J}{\partial w[k]}=\sum_{n} g[n]x_{\text{in}}[n+k]$$

The same results can be found using the general formula above. For $k=0$, $\sum_{n} g[n] x_{\text{in}}[n]=g[0]x_{\text{in}}[0]+g[1]x_{\text{in}}[1]+g[2]x_{\text{in}}[2]$. For $k=1$, $\sum_{n} g[n] x_{\text{in}}[n+1]=g[0]x_{\text{in}}[1]+g[1]x_{\text{in}}[2]+g[2]x_{\text{in}}[3]$. That being said, observing the formula, the sum over $n$ ranges over every output position where the convolution layer produces a value. The reason that convolution layers are trainable is because the gradient needs the incoming gradient, $g[n]$, and the input. $w[k]$ being a single parameter in every position means that its gradient is the sum of contributions from all positions, so without the rule it would be difficult to update weight appearance in various positions.

The reason convolution layers learn from less data than a fully connected layer is because each weight is able to get the evidence of every position in its image. Meanwhile, a fully connected layer has every output neuron connected to every input neuron according to Section 24.4. So each weight has evidence from a single connection, so the amount of weights each layer has to learn compared to the convolution layer is significantly larger than the convolution layer.

Part B — Backpropagation for an MLP   [35 points]¶

Each layer is a class with a forward method, a backward method and a params method, following Figure 14.11. The one difference from the book is that we process a batch of datapoints at once, stored as the rows of a matrix:

Chapter 14 this assignment
one datapoint column vector $\mathbf{x} \in \mathbb{R}^{N}$ row of $X \in \mathbb{R}^{B \times N}$
linear layer $\mathbf{x}_{\text{out}} = W\mathbf{x}_{\text{in}} + \mathbf{b}$ X_out = X_in @ W.T + b
gradient row vector $\mathbf{g} \in \mathbb{R}^{1\times M}$ G, shape (B, M), same as X_out

The contract every layer follows.

  • forward(x) computes the output and saves whatever backward will need on self.
  • backward(g_out) receives $\partial J/\partial \mathbf{x}_{\text{out}}$ (same shape as the output), stores the parameter gradients in self.dW, self.db, and returns $\partial J/\partial \mathbf{x}_{\text{in}}$ (same shape as the input).
  • params() returns a list of (name, parameter, gradient) triples.

class Linear:
    """
    x_out = x_in @ W.T + b
      x_in : (B, n_in)     W : (n_out, n_in)     b : (n_out,)     x_out : (B, n_out)
    """
    def __init__(self, n_in, n_out, rng):
        self.W = rng.standard_normal((n_out, n_in)) * np.sqrt(2.0 / n_in)   # He initialization
        self.b = np.zeros(n_out)
        self.dW = np.zeros_like(self.W)
        self.db = np.zeros_like(self.b)

    def forward(self, x):
        self.x = x                        # save the operating point for backward
        return x @ self.W.T + self.b

    def backward(self, g_out):
        """g_out: (B, n_out).  Set self.dW and self.db; return dJ/dx_in of shape (B, n_in)."""
        self.dW = g_out.T @ self.x
        self.db = np.sum(g_out, axis=0)
        return g_out @ self.W

    def params(self):
        return [("W", self.W, self.dW), ("b", self.b, self.db)]

class SoftmaxCrossEntropy:
    def forward(self, z, y):
        """z: (B, K) logits.  y: (B,) integer labels.  Returns the mean loss (a float)."""
        s = z - np.max(z, axis=1, keepdims=True)
        log_sum_exp = np.log(np.sum(np.exp(s), axis=1, keepdims=True)) # used AI to figure out why SoftmaxCrossEntropy was FAIL. I forgot to apply the log function to the equation
        log_probs = s - log_sum_exp
        self.probs = np.exp(log_probs)
        self.y = y
        B = z.shape[0]
        return -np.mean(log_probs[np.arange(B), y])

    def backward(self):
        """Returns dJ/dz, shape (B, K)."""
        B = self.y.shape[0]
        g = self.probs.copy()
        g[np.arange(B), self.y] -= 1
        return g / B

class MLP:
    def __init__(self, sizes, rng):
        self.layers = []
        for i in range(len(sizes) - 1):
            self.layers.append(Linear(sizes[i], sizes[i + 1], rng))
            if i < len(sizes) - 2:
                self.layers.append(ReLU())
        self.loss = SoftmaxCrossEntropy()

    def forward(self, x):
        for layer in self.layers:
            x = layer.forward(x)
        return x

    def backward(self, g):
        """g is dJ/d(output of the last layer). Propagate it back through every layer."""
        for layer in reversed(self.layers):
            g = layer.backward(g)
        return g

    def params(self):
        out = []
        for layer in self.layers:
            out += layer.params()
        return out

    def step(self, lr):
        """One step of gradient descent on every parameter."""
        for name, p, g in self.params():
            p -= lr * g

def train(net, x_train, y_train, x_test, y_test, epochs, lr, batch_size, rng):
    """Returns a list of per-batch training losses."""
    history = []
    for epoch in range(epochs):
        for xb, yb in batches(x_train, y_train, batch_size, rng):
            # YOUR CODE HERE: forward pass, loss, backward pass, step.
            #                 Append the loss (a float) to history.
            logits = net.forward(xb)
            loss = net.loss.forward(logits, yb)
            g = net.loss.backward()
            net.backward(g)
            net.step(lr)
            history.append(float(loss))
        print(f"epoch {epoch + 1}:  last batch loss {history[-1]:.4f},  "
              f"test accuracy {evaluate(net, x_test, y_test):.4f}")
    return history
