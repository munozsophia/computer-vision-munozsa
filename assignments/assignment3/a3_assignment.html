Part A — A convolutional network in NumPy   [35 points]¶

Now images keep their spatial shape: a batch is a 4-D array of shape (B, C, H, W).

Loops over pixels in Python will be far too slow to train on MNIST. Use sliding_window_view (already imported). For a padded input xp of shape (B, C, H, W),

win = sliding_window_view(xp, (k, k), axis=(2, 3))     # shape (B, C, H', W', k, k)

gives every $k\times k$ window at once, and np.einsum can then combine the windows with the kernel in a single call. Pass optimize=True to einsum for speed.

A1. Convolutional layer   [14 points]¶

Implement forward [5] and backward [9] for a stride-1 convolution with zero padding. As in Chapter 24, this is really cross-correlation:

$$x_{\text{out}}[b, o, n, m] = b_o + \sum_{c}\sum_{i,j} W[o, c, i, j]\; x_{\text{pad}}[b, c, n+i, m+j].$$

backward must set self.dW and self.db and return $\partial J/\partial x_{\text{in}}$.

Hints for backward.

  • self.dW: by Assignment 2, Question A2(b), each weight collects a contribution from every position and every example. It is again a sum over windows.

  • $\partial J / \partial x_{\text{in}}$: there are two good approaches.

    1. Scatter-add: start from zeros of the padded shape, and add each output gradient back onto the $k\times k$ window of inputs that produced it. Loop over the $k^2$ kernel offsets rather than over pixels, so there are only 9 iterations for a $3\times 3$ kernel.
    2. Full convolution: it is a fact, which you may use without proof, that $\partial J / \partial x_{\text{pad}}$ is the gradient g_out, padded by $k-1$ on every side and cross-correlated with the kernel flipped in both spatial directions, W[:, :, ::-1, ::-1], with the roles of the input and output channels exchanged.

    Either way, remember to crop away the padding at the end.

class Conv2D:
    """
    x : (B, C_in, H, W)   W : (C_out, C_in, k, k)   b : (C_out,)
    Stride 1, zero padding of `pad` on each side. With pad = (k-1)//2 the output is also H x W.
    """
    def __init__(self, c_in, c_out, k, pad, rng):
        self.W = rng.standard_normal((c_out, c_in, k, k)) * np.sqrt(2.0 / (c_in * k * k))
        self.b = np.zeros(c_out)
        self.k, self.pad = k, pad
        self.dW = np.zeros_like(self.W)
        self.db = np.zeros_like(self.b)

    def forward(self, x):
        p = self.pad
        xp = np.pad(x, ((0, 0), (0, 0), (p, p), (p, p))) # pad only two spatial axes
        win = sliding_window_view(xp, (self.k, self.k), axis=(2, 3)) # type: ignore
        self.xp, self.win = xp, win # save for backward
        out = np.einsum('bcnmij,ocij->bonm', win, self.W, optimize=True)
        return out + self.b[:, None, None] # make b broadcast over B, H', W'

    def backward(self, g_out):
        p = self.pad
        H = self.xp.shape[2] - 2 * p
        W_in = self.xp.shape[3] - 2 * p
        self.dW = np.einsum('bonm,bcnmij->ocij', g_out, self.win, optimize=True)
        self.db = g_out.sum(axis=(0, 2, 3))
        dxp = np.zeros_like(self.xp)
        Hp, Wp = g_out.shape[2], g_out.shape[3]
        for i in range(self.k):
            for j in range(self.k):
                dxp[:, :, i:i+Hp, j:j+Wp] += np.einsum('bonm,oc->bcnm', g_out, self.W[:, :, i, j])
        return dxp[:, :, p:p+H, p:p+W_in]

    def params(self):
        return [("W", self.W, self.dW), ("b", self.b, self.db)]

A2. Max pooling   [6 points]¶

Implement non-overlapping $2\times2$ max pooling. You may assume $H$ and $W$ are even.

Hints. x.reshape(B, C, H//2, 2, W//2, 2) puts each $2\times2$ block on its own pair of axes, so the forward pass is a single max. For the backward pass, the gradient flows only to the position that won the max in each block, and is zero everywhere else.

In [4]:
class MaxPool2D:
    def forward(self, x):
        B, C, H, W = x.shape
        xr = x.reshape(B, C, H // 2, 2, W // 2, 2)
        out = xr.max(axis=(3, 5)) # (B, C, H/2, W/2)
        self.mask = (xr == out[:, :, :, None, :, None]) # true where the block's max sits
        self.shape = x.shape
        return out

    def backward(self, g_out):
        g = g_out[:, :, :, None, :, None] * self.mask # spread g_out over each block, keep winner
        return g.reshape(self.shape) # back to (B, C, H, W)

    def params(self):
        return []

class Flatten:
    def forward(self, x):
        self.shape = x.shape
        return x.reshape(x.shape[0], -1)

    def backward(self, g_out):
        return g_out.reshape(self.shape)

    def params(self):
        return []

Part B — Attention   [19 points]¶

The convolution of Part A got its efficiency by assuming that an image is local and translation invariant. A transformer assumes neither. It cuts the image into patches, calls each patch a token, and lets every token look at every other token through an attention layer whose weights are computed from the data at run time.

Throughout Part B a batch of tokens is an array of shape (B, N, d): B examples, N tokens each, d features per token. One head of self-attention, Chapter 26 §26.3, is

$$Q = X W_q^\top,\qquad K = X W_k^\top,\qquad V = X W_v^\top,$$ $$S = \frac{QK^\top}{\sqrt{m}},\qquad A = \operatorname{softmax}_{\text{rows}}(S), \qquad X_{\text{out}} = A V,$$

where $X$ is $N \times d$, each projection matrix is $m \times d$, and $S$ and $A$ are $N \times N$.

The architecture these pieces are assembled into — the vision transformer of Chapter 26 §26.6 — is this:

patchify → linear embedding → positional codes → residual(layernorm, multi-head attention) → residual(layernorm, MLP) → layernorm → mean over tokens → linear classifier

We are not building it here; the point of Part B is to understand why it is built that way, because almost every decision in that line is forced by a property of attention that you can derive in a few lines. B1 to B3 are those derivations, and each one refers to the architecture above, so read it before you start. LayerNorm, Residual and MeanPool are in a3utils.py if you want to see what the named pieces actually do — Residual.backward in particular is two lines and worth a look.

B1 to B3 are pen and paper; B4 is a short implementation.

B1. Attention is a weighted average   [5 points]¶

Write $a_n^\top$ for the $n$-th row of $A$ and $v_j^\top$ for the $j$-th row of $V$.

(a) [2] Show that every row of $A$ has non-negative entries that sum to one, whatever $S$ is.

(b) [2] Hence write the $n$-th output token as a combination of the value vectors, and state what set the output is confined to. (The set has a name; it is determined by $v_1,\dots,v_N$ and does not depend on $S$ at all.) One consequence: attention on its own cannot produce a token that is more extreme than every token it is given. Which later component of the block can?

(c) [1] At initialisation the projection matrices are small, so every entry of $S$ is close to zero. What is $A$ then, and what operation is the attention layer performing on the tokens?

Your answer — B1¶

(a) From Section 26.6.2 Self-Attention, Equation 26.6 $A=softmax(\frac{QK^T}{\sqrt m})$ is the softmax within each row which weights sum to 1 according to Section 26.6.

For example, a row of scores $S=s_1,s_2,s_3=(0,1,2)$ with the softmax weight for position $j$ is $a_j=\frac{e^{s_j}}{e^{s_1}+e^{s_2}+e^{s_3}}$. Once substituted into the equation we get $a_j=\frac{e^{s_j}}{e^0+e^1+e^2}=\frac{e^{s_j}}{1+2.72+7.39}=\frac{e^{s_j}}{11.11}$. And to get the weights, I divided the previosly used values by the sum:

$e^{0}=1$ $\frac{1}{11.11}=0.09$

$e^{1}=2.72$ $\frac{2.72}{11.11}=0.24$

$e^{2}=7.39$ $\frac{7.39}{11.11}=0.67$

Which add up to $1$. Looking at row softmax, $A[n,j]=\frac{e^{S[n,j]}}{\sum_l{e^{S[n,l]}}}$. Due to the exponential function, every entry ends up being positive no matter if it is positive, negative, or zero. The entries of a row add up to 1 due to every numerator of a row being divided by the same denominator (their shared sum) and it not being dependent on $j$.

(b) From Section 26.5-26.6, Attention is a weighted average whose weights are decided on the fly. Taking this into account and my conclusion from Part (a) above, the weights $a_{nj}$ sum to $1$ as mentioned before. The $n$-th output token is $a_{j}=\sum_j{A[n,j]=\frac{\sum_j{e^{s_nj}}}{\sum_l{e^{s_nl}}}}$, which is a sum of the value vectors. So it lies in the denominator of $v_1,...,v_N$, a set that depends only on the value vectors. Consequently, attention alone cannot produce a token that is more extreme than every token it is given. A later component of the block that can produce a token more extreme than every token it's given is the MLP since the same MLP is applied to every token separately according to Section 26.7.

(c) Now, since every score in a row is about 0, $e^0=1$. So each weight is 1 divided by the number of entries in the row $N$, so the denominator would be $N$ and that would make each weight $\frac{1}{N}$. Every token would end up with the same output because the output doesn't depend on $n$. The operation that is on the whole set of tokens would be mean pooling because according to Section $26.5-26.5$, mean pooling averages its inputs with fixed, equal weights, which in this case is $\frac{1}{N}$.

B2. Why divide by $\sqrt{m}$   [5 points]¶

(a) [3] Let $q, k \in \mathbb{R}^m$ be independent random vectors whose entries are independent, have zero mean and unit variance. Show that $$\mathbb{E}[q^\top k] = 0 \qquad\text{and}\qquad \operatorname{Var}[q^\top k] = m .$$

(b) [2] So the unscaled logits of one row have standard deviation $\sqrt{m}$. Take $m = 64$ and suppose two logits in a row differ by two standard deviations. Ignoring the other entries of the row, compute the softmax weight the smaller one receives. Then use $$\frac{\partial p_i}{\partial s_j} = p_i(\delta_{ij} - p_j)$$ to say what has happened to the gradient reaching that logit, and explain in one sentence why dividing by $\sqrt{m}$ prevents it.

Your answer — B2¶

(a) From Section 26.6.2 The Scaling in Equation 26.6 $A=softmax(\frac{QK^T}{\sqrt m})$

The dot product as a sum is below:

$$q^\top k=\sum_{i=1}^m q_i k_i$$

For the mean of one term, $q_i$ and $k_i$ are independent from each other, so $\mathbb{E}[q_i k_i]=\mathbb{E}[q_i]\cdot\mathbb{E}[k_i]=0\cdot0=0$. Then the mean of the sum gives $\mathbb{E}[q^\top k]=\sum_i \mathbb{E}[q_i k_i]=0$.

For the variance of one term, since $\operatorname{Var}[q_i]=\mathbb{E}[q_i^2]-(\mathbb{E}[q_i])^2=\mathbb{E}[q_i^2]=1$, and likewise for $k_i$. Since $\mathbb{E}[q_i k_i]=0$, we have $\operatorname{Var}[X]=\mathbb{E}[X^2]-(\mathbb{E}[X])^2=\mathbb{E}[X^2] \rightarrow \mathbb{E}[(q_i k_i)^2]=\mathbb{E}[q_i^2 k_i^2]=\mathbb{E}[q_i^2]\cdot\mathbb{E}[k_i^2]=1\cdot1=1$. Since $q_i$ and $k_i$ are independent, and that's why the expectation of $q_i^2 k_i^2$ product factors.

For the sum over the terms $m$, $q_i k_i$ are independent from each other so for the variance of the sum is basically equivalent to the sum of the variances, where you add up $m$ copies of the one-term result. So, $\operatorname{Var}[q^\top k]=\sum_i \operatorname{Var}[q_i k_i]=\sum_{i=1}^m 1=m$.

This agrees with Section 26.6.2, where the dot products grow with dimension if the entries of q and k are roughly independent with unit variance, $q^\top k$ is a sum of $m$ unit-variance terms. So its variance is $m$, and its standard deviation is $\sqrt m$.

(b) For the logits gap, $\sqrt m=\sqrt64=8$, so two standard deviations is a gap of $16$.

For the two logits ignoring the rest, one is $s_a$ and the other is $s_b=s_a+gap$. For the weight of the smaller logit, $\frac{e^{s_a}}{e^{s_a}+e^{s_b}}=\frac{e^{s_a}}{e^{s_a}+e^{s_a+gap}}=\frac{1}{1+e^{gap}}=\frac{1}{1+e^{16}}=\frac{1}{1+8886110.52}=\frac{1}{8886111.52}=1.125e-7$. This means the weight is near zero.

As for the gradient, using $\frac{\partial p_i}{\partial s_j} = p_i(\delta_{ij} - p_j)$, for the smaller logit $i$ where $j=i$. $\frac{\partial p_i}{\partial s_i}=p_i(1-p_i)$. Since $p_i$ is really tiny, essentially 0, almost no gradient flows back to that logit, so the attention stops being soft, and stops learning. So by dividing by $\sqrt m$, the standard deviation is $1$, so the gap in the same scenario is $\frac{16}{\sqrt 64}=\frac{16}{8}=2$.

So the weight for the new gap is $\frac{1}{1+e^2}=\frac{1}{1+7.39}=\frac{1}{8.39}=0.1192$. This value isn't as tiny compared to the weight that was not divided by $\sqrt m$. Dividing by $\sqrt m$ is able to keep the gap the same size (return the scores to unit scale) no matter how wide the keys are, so the softmax behaves the same in a small model and a large one.

B3. Permutation equivariance, and why positional codes exist   [5 points]¶

Let $P$ be an $N \times N$ permutation matrix, so that $PX$ is $X$ with its rows (its tokens) reordered, and $P^\top P = I$.

(a) [3] Show that one head of self-attention is equivariant to this reordering: $$\text{attention}(PX) = P \cdot \text{attention}(X).$$ Work through $Q$, $K$, $S$, $A$ and the output in turn. You will need the fact that applying the softmax to each row of $PSP^\top$ gives $PAP^\top$; say in one line why that is true.

(b) [2] The architecture ends with MeanPool, which averages over tokens and is therefore permutation invariant. Every layer in between — LayerNorm, the per-token MLP, the residual additions, the embedding Linear — acts on one token at a time. Combine this with part (a) to say exactly what the network would predict for an image whose patches had been shuffled, if the positional codes were removed. Be precise about the word exactly: is the claim that the two predictions are close, or that they are identical? Say which, and why.

Your answer is a claim about a real network that can be checked by running it, so make it sharp enough to be wrong.

Your answer — B3¶

(a) Assume $P$ is a permutation matrix, $P^\top P=I$, and $(PQ)^\top=Q^\top P^\top$

$$Q'=(PX) W_q^\top=P(XW_q^\top)=PQ$$ $$K'=(PX) W_k^\top=P(XW_k^\top)=PK$$ $$V'=(PX) W_v^\top=P(XW_v^\top)=PV$$ $$S'=\frac{Q' K'^\top}{\sqrt m}=\frac{(PQ)(PK)^\top}{\sqrt m}=\frac{(PQ)(K^\top P^\top)}{\sqrt m}=P(\frac{QK^\top}{\sqrt m})P^\top=PSP^\top$$ $$A'=softmax_{rows}(S')=softmax_{rows}(PSP^\top)=P softmax_{rows}(S)P^\top=PAP^\top$$

Each row of $PSP^\top$ is a row of $S$ with its entries reordered, and softmax doesn't depend on the order of the entries within a row, it is just able to treat each entry the same way so the output row is the reordered softmax row. The $P$, left factor, reorders the rows themselves.

$O=AV$ is the original attention output.

$$X_{out}'=A'V'=(PAP^\top)(PV)=PA(P^\top P)V=PA(I)V=P(AV)=PO$$

With Section 26.8 Permutation Equivariance to back up my conclusion, $\text{attention}(PX) = P \cdot \text{attention}(X)$ is the scrambled input that the output scrambles the same way.

(b) Every layer before the MeanPool is permutation equivariant, so composing them gives a network stage that is permutation equivariant, and shuffling the input tokens shuffles the output tokens in the same manner. Taking note of my answer in part (a), attention and per-token layers apply the same function to every row independently.

The MeanPool is able to average over the tokens and the average is invariant to the order of its terms, so the reordering is irrelevant. So for an image with shuffled patches and no positional codes, the predictions of the network and the original image are identical to each other. This is because every step is an exact identity. From Section 26.11, with positional codes used the permutation invariance is broken because the positional embeddings tag each token position which makes the representation sensitive to patch order.

B4. Row softmax   [4 points]¶

Implement the softmax applied independently to each row — that is, along the last axis of an array with any number of leading axes, so that the same layer serves logits of shape (B, K) and attention scores of shape (B, N, N).

The backward pass is Assignment 2, Question A1, lifted to many rows at once. For one row, $$\frac{\partial p_i}{\partial s_j} = p_i(\delta_{ij} - p_j) \qquad\Longrightarrow\qquad \left(\frac{\partial J}{\partial s}\right)_i = p_i\Big(g_i - \sum_j g_j p_j\Big),$$ where $g = \partial J/\partial p$. The sum is one scalar per row, so you can compute this without ever forming the $n \times n$ Jacobian. That matters more here than it did in Assignment 2: inside an attention layer this softmax is applied to an $N \times N$ score matrix for every example in the batch, so the explicit Jacobians would be an $N \times N \times N$ array per example — at $N = 16$ and a batch of 64, a quarter of a million numbers per layer, to compute something that needs one scalar per row.

Use the stability trick from Assignment 2, Question A3: subtract each row's maximum first.

In [13]:
class RowSoftmax:
    """
    Softmax along the LAST axis, applied independently to every row.
    x : (..., n)  ->  p : (..., n), each row non-negative and summing to 1.
    """
    def forward(self, x):
        e = np.exp(x - x.max(axis=-1, keepdims=True)) # subtract each row's max
        self.p = e / e.sum(axis=-1, keepdims=True) # normalize each row to sum to 1 by dividing by the sum of each row
        return self.p

    def backward(self, g_out):
        dot = (g_out * self.p).sum(axis=-1, keepdims=True) # one scalar per row, the dot product of g_out and p
        return self.p * (g_out - dot) # the gradient of the softmax is p * (g_out - dot), where dot is the sum of g_out * p for each row

    def params(self):
        return []
